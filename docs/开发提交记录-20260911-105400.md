## 开发概述

按设计文档实施 M1/M2（reclaim 延迟定时器化，方案 A）+ M3（unlock mount L3 兜底串行化）+ M4（线程禁令规范条款）。核心目标：appspawn 主进程（全部孵化器变体）全程单线程，reclaim 语义保留但延迟到事件循环低峰期由主线程执行。

## 修改文件列表

| 文件 | 修改点 | 设计映射 |
|------|--------|----------|
| `modules/ace_adapter/ace_adapter.cpp` | 移除 `std::thread` reclaim 线程与 `<thread>` 依赖；新增 `ReclaimTimerCallback`（延迟回调 + 耗时打点）；`DlopenAppSpawn` 统一为延迟定时器路径（全孵化器一致，消除 appspawn/非 appspawn 分支）；参数 `persist.appspawn.reclaim.delay`（默认 32s，负值回退默认）；timer 创建/启动失败降级为跳过 reclaim（打 ERROR） | M1+M2 |

| `AGENTS.md` | Code conventions 增加 Single-thread rule 条款（禁线程 + 替代模式指引 + 参考实现锚点） | M4 |

## 关键实现决策（与设计的偏差说明）

1. **参数名**：设计文档示例 `startup.appspawn.reclaim.delay`，实现取 `persist.appspawn.reclaim.delay`——与仓内既有 `persist.appspawn.preload` / `persist.appspawn.preloadets` 参数族一致（ace_adapter.cpp:96-97,260 先例）
2. **timer 失败降级**：`LE_CreateTimer`/`LE_StartTimer` 失败时跳过 reclaim（页缓存驻留无害），不回退同步执行（避免阻塞 preload 与服务就绪），打 ERROR 日志可观测
3. **规范条款落点**：`docs/c++CodeGuide.md` 不存在（流程文档描述过时），M4 落在 `AGENTS.md` Code conventions 段；另注：AGENTS.md 声明 docs/ 为生成知识库不手改，本流程产物（设计/提交记录/变更摘要，带时间戳新增文件）按 appspawn-dev 流程要求存放 docs/，未改动任何既有生成文档
4. **耗时测量**：`std::chrono::steady_clock`（与 sandbox_unlock_mount.cpp 既有风格一致）
